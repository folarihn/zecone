# DEX and marketplace integration notes

Reviewed 15 October 2026. No arbitrary router execution enabled, no pool deployed and no new liquidity or paid API provisioned.

The existing Base Sepolia controlled V2-style AMM adapter remains the only enabled swap path. Its locally configured ZTEST token, exact router/route, output floor, deadline, bounded native spend and settlement receipt checks remain authoritative. Token balances and executable quotes come from its existing service; unavailable liquidity must produce an unavailable state, not a sample quote. Ethereum Sepolia and Robinhood swaps remain disabled.

Addresses are research observations; no Phase 6 bytecode or liquidity validation was performed against these external routers.

For the recommended later Uniswap prototype, recheck chain ID/code hashes and resolve the pool through the pinned factory. Query reserves/liquidity and Quoter at a referenced block, choose one allowlisted test token pair and fee tier, and reject empty or manipulated pools. SDK amounts/decimals are not price oracles. Use exact approvals capped to the trade amount and reset residual allowances where needed. Avoid universal Permit2 allowances and arbitrary router callbacks. If the chosen router lacks a per-call deadline, enforce the intent deadline in the controlled executor immediately before calling it.

The executor must fix recipient and output asset; validate minimum output and maximum input, reentrancy protection, callback sender/pool identity, WETH wrapping/unwrapping and final balance delta. Block unknown multicalls, fee-on-transfer/rebasing tokens and unsupported NFT actions. Simulate before payment and before destination submission, reserve relayer value plus worst-case fees, and recheck solvency before execution. A price move or sold/expired listing during ten Zcash confirmations enters recovery, never silently expands slippage or resubmits an uncertain payment.

Actual gas must be estimated on the configured network at execution time, including OP Stack data fee reserves where applicable. Public RPCs need no new credential for basic reads but may rate-limit; commercial routing/catalog APIs may require credentials or paid plans. No paid service is assumed. A quote's expiry and its economic conversion rate are separate: ZecOne's current ZEC conversion remains simulated and the destination asset comes from prefunded liquidity.

NFT discovery remains the existing controlled marketplace/Seaport catalog and known-contract ownership reads. OpenSea API imports/previews retain protocol, chain, recipient and expiry restrictions; native OpenSea Buy does not use ZEC. Rarible is a candidate for future standard wallet connectivity, not a verified Seaport execution source: its protocol/order formats need a separate adapter audit. Never assume EIP-6963 connection makes a marketplace listing eligible for settlement.
