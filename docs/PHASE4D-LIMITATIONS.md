# Phase 4D limitations

- **Real API integration is proven; real OpenSea wallet connection is not.** The available in-app browser could inspect the actual picker but could not load an extension. Source and local popup tests are not installed-extension, Chrome-store or website interoperability evidence.
- The minimal extension requires a running, paired loopback wallet and an opener-preserving popup. Browser popup blocking, COOP, mixed-origin policies, enterprise extension policies or OpenSea's method requirements can block it. Do not weaken browser security to work around those failures.
- Only configured testnets can be signed/switched by the wallet. OpenSea mainnet network selection and production typed orders are intentionally unsupported. No production listing, offer, approval, transfer or purchase was signed.
- WalletConnect was visible on the real site but is not implemented. No relay project credential was provisioned.
- API read-only inspection supports Ethereum FULL_OPEN, one fixed-price ERC-721, native ETH, zero zone/hash, direct approval or the verified OpenSea conduit. Criteria, bundles, ERC-1155, dynamic prices, partial/restricted orders, contract-order/bulk-signature formats and ERC-20 prices are rejected. Other API networks are not enabled merely because `/chains` lists them.
- The mainnet inspection policy can inspect conduit and contract consideration recipients; the **existing Base Sepolia executor cannot execute those listings**. Its immutable controlled collection/seller/fee policy and zero-conduit rule remain intact. Extending execution would be separate reviewed work.
- API keys expire and can be revoked or quota-limited. The observed issued key expires on 2026-10-20. Actual individual-order responses still had a wrapper despite a documentation migration notice; validation supports both explicit shapes. Metadata is not authoritative ownership evidence.
- Fee classification depends on collection API policy; signatures and onchain reads authenticate the consideration, not a marketplace business-policy promise. Optional creator fees were not added. Inspection caps total non-seller fees at 5% of gross price.
- Simulation overrides hypothetical ETH balance. Gas estimates, listing status and previews are time-bound; nothing is reserved, paid, swapped or acquired. ZEC pricing is illustrative and the native payment fee is unquoted. No asset exchange or mainnet funding is implied.
- EOA/EIP-2098 seller signatures and onchain-validated orders are supported. General EIP-1271/bulk signature verification is not implemented. A valid past signature alone never suffices for availability.
- The local Node/OS, public RPC, lightwalletd and prefunded operator remain trusted. Local keys are plaintext testnet files. Private frontend/session access is not protection from same-user malware.
- Automatic refunds, trustless bridging, production deployment, Solana and Phase 5 remain out of scope. Prior Phase 4C live payment proof is reused with current deterministic regression; no new payment is represented as real.
